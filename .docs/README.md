## Project summary

llmConnect is a desktop application for managing browser-based LLM chats and local API profiles in one workspace. The app is designed to keep state local, separate browser sessions, and extract conversations into a structured dashboard view.

## Scope of the current implementation

- Browser tabs are isolated per model.
- Chats are extracted from supported browser providers and saved locally.
- Saved chats are grouped by category and project.
- API profiles are stored securely and shown in the dashboard.
